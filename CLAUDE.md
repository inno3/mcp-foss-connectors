# Reprise du projet

Lire [docs/REPRISE.md](docs/REPRISE.md) avant de poursuivre un chantier sur ce
depot. Ce document porte l'etat courant, les decisions arretees, les limites
connues et les prochaines actions. Le mettre a jour apres toute avancee
substantielle.

Deux points a verifier avant de lancer quoi que ce soit :

- le `.venv` du depot est casse depuis la restauration du poste ; la recette de
  remplacement est dans `docs/REPRISE.md`, section « Harnais de test » ;
- `docs/RELEASE.md` est la procedure de publication, et sa section 4bis dit ce
  qu'une mise a jour locale d'extension a le droit de toucher.
